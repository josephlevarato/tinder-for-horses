# Tinder for Horses

This project is just a way for me to explore Java and its abilities, through an excuses directly inspired by [Fireship](https://www.youtube.com/@Fireship).

# Goals

Non exhaustively:

- Postgres as database
- JWT to authenticate users
- Manage account, preferences, photos, bio, etc
- Realtime for matches, messages and notifications
- Angular for the front-end
- **Not a single line generated by AI**

# Setup / First run

1. Setup env file

```bash
cp .env.example .env
```

2. Docker

```bash
docker compose up -d
```

3. RustFS

- Reach [localhost:9001](http://localhost:9001) and authenticate using the credentials from [compose.yaml](./compose.yaml)
- Create a bucket with the name also inside the [compose.yaml](./compose.yaml)
- `browser` > `[your bucket's row]` > `settings` > `access policity` > set `public`
